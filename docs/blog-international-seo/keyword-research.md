## Field definitions

| Field | Description |
|---|---|
| **Keyword** | Target query phrase |
| **Country** | Primary market (IN / UK / UAE / ME) |
| **Search intent** | Informational / Commercial investigation / Transactional |
| **Content cluster** | PVD Partitions, Slim Profile/Entrance Doors, Railings, Corten Steel, PVD Hardware/Furniture, Architectural Metalwork |
| **Proposed destination URL** | Canonical route from `routes/web.php` or proposed regional path |
| **Classification** | Informational or Commercial |
| **Priority** | P1 (core revenue) / P2 (supporting) / P3 (long-tail) |
| **Existing or new** | `existing` = live route; `proposed` = not built; `blog-draft` = content file only |
| **Evidence source** | GSC, Ads Planner, Trends, SERP review, site config, or seed |
| **Notes** | Validation status, owner confirmation, hreflang implications |
